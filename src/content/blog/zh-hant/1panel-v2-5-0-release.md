1Panel v2.5.0 正式發布：全面重構 GPU 管理、vLLM 管理與模型服務，打通從模型準備、部署、監控、基準測試到接入 AI 閘道的本地模型部署全流程；虛擬機管理開放至社群版，運維報表開放至專業版，並帶來 1Panel MCP 服務管理、映像更新偵測與批次升級等能力。

2026 年 11 月 11 日，新一代的 Linux 伺服器管家 1Panel 正式發布 v2.5.0 版本。

1Panel v2.5.0 版本聚焦**提升本地模型部署體驗**進行全面升級，打通**從 GPU 管理、模型準備、模型部署、模型服務、基準測試到接入 AI 閘道對外提供 Token 服務**的全流程閉環。新版 1Panel 支援使用者在 AI 伺服器上快速部署和管理本地模型，使用者可以在面板中完成環境檢查、部署設定與執行監控等操作，有效減少在不同工具之間切換的重複操作。

與此同時，1Panel v2.5.0 版本將虛擬機管理功能完整開放給社群版使用者，運維報表功能開放給專業版使用者，並且帶來 1Panel MCP 服務管理、容器映像更新偵測與批次升級等實用功能，持續完善伺服器管理體驗。

已安裝使用者可以在面板右下角點擊「檢查更新」完成線上升級。完整變更見 [v2.5.0 Release](https://github.com/1Panel-dev/1Panel/releases/tag/v2.5.0)。

**感謝廣大社群使用者的持續回饋與支持，1Panel 期待與您攜手，共同打造更加高效、安全、智慧的 Linux 運維新體驗。**

## 亮點更新

### 全面重構 GPU 管理能力

在部署本地模型時，首先需要確認 GPU 是否被正確識別、驅動與容器執行環境是否準備就緒。1Panel v2.5.0 版本全面重構 GPU 管理能力，在統一介面集中展示裝置資訊、環境狀態、即時監控與歷史監控資訊，方便使用者瞭解目前裝置的使用條件與執行情況。

針對 NVIDIA 裝置，使用者可以在 1Panel 面板中檢查驅動與 NVIDIA Container Toolkit 狀態，並且查看相應的安裝與設定指引。對於不同廠商的裝置，1Panel 面板提供對應的環境診斷資訊，幫助使用者判斷還需要完成哪些準備工作。

模型執行後，使用者可以查看 GPU 使用率、記憶體佔用、溫度、功耗等即時指標，並且結合歷史曲線觀察負載變化。不同裝置展示對應的可用指標，方便排查資源緊張、負載偏高等情況，為部署調整提供參考。

### 整合精選模型、模型下載與 vLLM Recipes

面對不斷豐富的開源模型，選哪個模型？到哪裡下載？如何設定啟動參數？是使用者在部署前需要解決的問題。

1Panel v2.5.0 版本將精選模型、模型下載與 vLLM Recipes 串聯起來，讓使用者在準備模型時能夠獲得更加清晰的參考。使用者可以透過精選模型瞭解模型規格、適用場景與權重體積等資訊，然後再進入模型下載流程，準備部署所需的本地檔案。使用者可以對下載任務與本地模型檔案進行集中管理，方便後續部署時查找和使用。

對於需要參考啟動設定的模型，使用者還可以查看 vLLM Recipes 提供的部署設定範例，結合目標硬體、模型版本與執行環境調整參數，減少從零整理設定的工作。

### 重構 vLLM 管理功能，部署設定與執行監控更直觀

在模型檔案準備完成後，接下來的步驟是讓模型穩定地執行起來。1Panel v2.5.0 版本全面重構了 vLLM 管理功能模組，圍繞實例建立、部署設定與執行監控等環節完善操作流程，方便使用者按照所選模型和硬體環境組織部署操作。在建立實例時，使用者可以選擇相應的執行映像、模型檔案和啟動範本，並且設定 GPU 與模型啟動參數。

在實例執行後，使用者可以集中查看模型的執行狀態與日誌，並且透過監控頁面瞭解請求量、Token 輸送量與回應延遲等指標。結合 GPU 資源的使用情況，使用者可以更方便地觀察服務負載，為後續調整部署參數提供依據。

### 統一管理本地模型、公有雲與自建 AI 閘道帳號

在實際使用時，本地部署模型、公有雲模型和自建 AI 閘道往往同時存在。1Panel v2.5.0 版本全面重構「模型服務」功能模組，將本地模型服務、公有雲模型帳號，以及來自自建 AI 閘道的模型帳號進行集中管理，方便使用者查看和維護不同來源的模型服務。

使用者可以按照服務來源設定連線位址與存取憑證，查看帳號下的模型清單，並且進行連線驗證。模型部署和接入完成後，服務資訊與可用模型更加清晰，也為後續使用與基準測試提供了統一的選擇入口。

![圖 5 1Panel 模型服務管理介面](/blog/1panel-v2-5-0-release/image-05.webp)

### 預置多種基準測試方案

在模型上線後，使用者通常需要瞭解它在實際負載下的表現，包括首個 Token 傳回時長、持續輸出速度、提高並行後的輸送量等指標。1Panel v2.5.0 版本提供模型服務基準測試功能，支援使用者選擇目標服務和模型後，藉助快速驗證、常規測試與完整測試等預置方案，發起有針對性的效能測試。

使用者可以根據場景調整請求長度、輸出長度和並行設定，並且查看首字延遲（TTFT）、請求耗時與 Token 輸送量等測試結果。使用相同方案測試不同的模型部署設定，有助於使用者及時瞭解參數調整帶來的變化，為資源規劃與服務調優提供參考。

## 更多新增功能

- **虛擬機** — 虛擬機管理功能開放給社群版使用者；
- **概覽** — 新增 GPU 狀態檢視與 vLLM Token 輸送量監控功能，支援新增多個快捷目錄；
- **智能體** — 新增 DeepSeek Harness 和 OctoP 支援；
- **MCP 管理** — 新增 1Panel MCP 服務管理功能；
- **網站** — 支援在效能調整中設定反向代理逾時時間；
- **憑證** — 憑證申請後支援一次推送至多個本地目錄，支援匯入自簽根憑證；
- **容器** — 容器目錄支援批次上傳檔案；
- **容器** — 新增映像更新偵測與狀態提示，容器清單支援批次升級；
- **容器** — 支援搜尋 Docker Hub 遠端映像；
- **容器** — 新增 NVIDIA GPU 執行環境設定開關；
- **排程任務** — 存取 URL 任務支援設定 User-Agent 請求標頭；
- **資源同步** — 支援跨節點同步 PHP 擴充功能範本；
- **運維報表（X-Pack）** — 運維報表功能開放給專業版使用者；
- **多機管理（X-Pack）** — 支援使用既有安裝套件進行節點安裝與升級。

## 功能優化

- **應用商店** — 本地應用同步支援連動子節點，支援獨立設定與啟停映像前綴，並且減少同步時的資源請求；
- **智能體** — 更新 MiniMax Flash 模型清單與預設設定，以及 DeepSeek 預設模型名稱；
- **網站** — 優化 Brotli 設定尚未生效時的狀態提示；
- **執行環境** — 更新時待映像拉取完成後再停止原有容器，縮短因拉取映像造成的服務中斷時間；
- **資料庫** — 統一資料庫帳號與密碼驗證規則；
- **容器** — 支援按建立時間排序，清除排序後恢復預設順序，並且緩解清單長時間處於載入狀態的問題；
- **檔案** — 完善重新命名時 Esc 鍵與取消操作的處理，加強敏感檔案操作來源驗證與歷史記錄來源追蹤；
- **終端** — 優化深色模式下終端快捷入口的邊框顯示；
- **介面設定** — 統一任務日誌與刪除確認對話框，更新 1Panel 企業版登入頁背景；
- **日誌稽核** — 完善可信任代理場景下的用戶端 IP 記錄與登入資訊留存機制；
- **面板設定** — 支援刪除已撤銷的 API Key，完善備份儲存與 HTTPS 代理憑證驗證機制，並且支援自訂 CA 憑證；
- **系統** — 統一表格提示框的位置，提高清單頁每頁的筆數上限，並且優化表格回應式版面；
- **系統** — 加強過期工作階段與憑證使用的存取限制，完善外部資源請求的 TLS 憑證驗證機制，升級 Markdown 與 HTML 解析相依套件；
- **多機管理（X-Pack）** — 優化節點間 SFTP 上傳速度，延長節點資料同步的重試時間。

## 問題修復

- **應用商店** — 修復了以「+」或「-0」開頭的數值型密碼在安裝或修改應用參數時被改寫的問題；
- **應用商店** — 修復了升級應用時環境變數值被改寫、已下架版本的應用無法升級的問題；
- **應用商店** — 修復了透過節點代理存取時應用圖示重新導向異常，以及資源快取重新整理和 PHP 執行環境版本選項異常的問題；
- **智能體** — 修復了 Hermes 微信頻道掃碼對接時提示模組缺失、無法顯示 QR 碼的問題；
- **智能體** — 修復了 OpenClaw 升級後的 Feishu 外掛相容性問題，並且保留了舊版 Feishu 設定；
- **網站** — 修復了 PHP 執行環境變更未同步到子網站的問題；
- **執行環境** — 修復了專案終端提示找不到容器、無法連線的問題；
- **資料庫** — 修復了管理工具入口未讀取應用自訂 Web 存取位址的問題；
- **容器** — 修復了編輯容器後返回清單時搜尋條件遺失，以及應用實例名稱含大寫字母時無法清理日誌的問題；
- **檔案** — 修復了重新命名時直接覆蓋同名目標檔案、下載儲存路徑可能超出所選目錄，以及 tar 壓縮指令參數注入的問題；
- **終端** — 修復了新增節點後自動金鑰未正確顯示，連線時仍需輸入 SSH 密碼的問題；
- **排程任務** — 修復了指令碼庫同步時使用舊資源快取的問題；
- **日誌稽核** — 修復了切換網站 PHP 版本及刪除 PHP 執行環境時，操作日誌顯示資源 ID 而非名稱的問題；
- **面板設定** — 修復了重新啟用安全入口後無法正常存取面板，以及備份帳號按名稱搜尋異常的問題；
- **系統** — 修復了使用 1pctl 指令修改密碼時，未正確遵循密碼複雜度設定的問題；
- **系統** — 修復了夏令時間結束後在重複時間段校時導致系統時鐘回撥一小時的問題；
- **WAF（X-Pack）** — 修復了開啟網站設定時報錯，以及社群版子節點基礎介面未放行的問題；
- **網站監控（X-Pack）** — 修復了請求日誌統計報錯的問題。
