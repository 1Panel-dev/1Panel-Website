1Panel v2.5.0이 출시되었습니다. 이번 릴리스는 GPU 관리, vLLM 관리, 모델 서비스를 전면 재구성하여 모델 준비, 배포, 모니터링, 벤치마크, 그리고 AI Gateway를 통한 공개까지 로컬 모델 도입의 전체 흐름을 하나로 연결합니다. 가상 머신 관리는 이제 커뮤니티 에디션 사용자에게 완전히 개방되며, 운영 리포트는 프로페셔널 에디션 사용자에게 제공됩니다. 또한 1Panel MCP 서비스 관리, 컨테이너 이미지 업데이트 감지와 일괄 업그레이드도 새롭게 추가되었습니다.

2026년 11월 11일, 차세대 Linux 서버 관리 패널인 1Panel이 v2.5.0을 공식 출시했습니다.

1Panel v2.5.0은 **로컬 모델 도입 경험 개선**에 초점을 맞춥니다. **GPU 관리, 모델 준비, 모델 배포, 모델 서비스, 벤치마크, 그리고 AI Gateway를 통한 Token 서비스 제공**까지의 전체 순환을 연결합니다. 새 버전에서는 AI 서버에서 로컬 모델을 빠르게 배포하고 관리할 수 있으며, 환경 점검, 배포 설정, 실행 모니터링을 패널에서 완료할 수 있어 여러 도구를 오가는 반복 작업을 줄여 줍니다.

동시에 1Panel v2.5.0은 가상 머신 관리 기능을 커뮤니티 에디션 사용자에게 완전히 개방하고, 운영 리포트 기능을 프로페셔널 에디션 사용자에게 개방했습니다. 또한 1Panel MCP 서비스 관리, 컨테이너 이미지 업데이트 감지 및 일괄 업그레이드와 같은 실용적인 기능을 추가하여 서버 관리 경험을 지속적으로 개선합니다.

기존 사용자는 패널 오른쪽 아래의 **업데이트 확인**을 클릭하여 온라인 업그레이드를 진행할 수 있습니다. 전체 변경 사항은 [v2.5.0 릴리스](https://github.com/1Panel-dev/1Panel/releases/tag/v2.5.0)에서 확인할 수 있습니다.

**커뮤니티의 지속적인 피드백과 지원에 감사드립니다. 1Panel은 더욱 효율적이고 안전하며 지능적인 Linux 운영 경험을 함께 만들어 가기를 기대합니다.**

## 주요 하이라이트

### GPU 관리 전면 재구성

로컬 모델을 배포하기 전에 먼저 GPU가 올바르게 인식되는지, 드라이버와 컨테이너 런타임이 준비되었는지 확인해야 합니다. 1Panel v2.5.0은 GPU 관리를 전면 재구성하여 장치 정보, 환경 상태, 실시간 모니터링과 이력 모니터링을 하나의 화면에 모았습니다. 이를 통해 현재 장치의 사용 조건과 실행 상태를 한눈에 파악할 수 있습니다.

NVIDIA 장치의 경우 패널에서 드라이버와 NVIDIA Container Toolkit 상태를 확인하고 관련 설치 및 설정 안내를 볼 수 있습니다. 다른 제조사의 장치에 대해서는 패널이 해당 환경 진단 정보를 제공하여 어떤 준비 작업이 남았는지 판단할 수 있도록 돕습니다.

모델이 실행된 후에는 GPU 사용률, 메모리 사용량, 온도, 전력 소비 등의 지표를 실시간으로 확인하고 이력 곡선으로 부하 변화를 관찰할 수 있습니다. 장치별로 지원되는 지표가 표시되므로 리소스 부족이나 높은 부하 상황을 진단하고 배포 조정에 참고할 수 있습니다.

### 엄선 모델, 모델 다운로드, vLLM Recipes 통합

오픈소스 모델이 계속 늘어나면서 어떤 모델을 선택할지, 어디서 다운로드할지, 시작 파라미터를 어떻게 설정할지는 배포 전에 해결해야 할 문제입니다.

1Panel v2.5.0은 엄선 모델, 모델 다운로드, vLLM Recipes를 연결하여 모델 준비를 보다 명확한 참고 정보를 바탕으로 진행할 수 있게 합니다. 엄선 모델 목록에서 모델 사양, 적합한 사용 사례, 가중치 크기 등을 확인한 뒤 다운로드 흐름으로 이동하여 배포에 필요한 로컬 파일을 준비할 수 있습니다. 다운로드 작업과 로컬 모델 파일은 중앙에서 관리할 수 있어 나중에 찾아 재사용하기 쉽습니다.

시작 설정 참고가 필요한 모델은 vLLM Recipes에서 제공하는 배포 설정 예시를 확인하고 대상 하드웨어, 모델 버전, 실행 환경에 맞춰 파라미터를 조정할 수 있어 설정을 처음부터 구성하는 수고를 줄일 수 있습니다.

### vLLM 관리 재구성으로 더 명확해진 배포 설정과 실행 모니터링

모델 파일이 준비되면 다음 단계는 모델을 안정적으로 실행하는 것입니다. 1Panel v2.5.0은 vLLM 관리 모듈을 전면 재구성하여 인스턴스 생성, 배포 설정, 실행 모니터링 등의 절차를 정비했습니다. 선택한 모델과 하드웨어 환경에 맞춰 배포 작업을 구성할 수 있습니다. 인스턴스를 생성할 때 실행 이미지, 모델 파일, 시작 템플릿을 선택하고 GPU 및 모델 시작 파라미터를 설정할 수 있습니다.

인스턴스가 실행된 후에는 모델의 상태와 로그를 한곳에서 확인하고 모니터링 페이지에서 요청량, Token 처리량, 응답 지연 등의 지표를 볼 수 있습니다. GPU 리소스 사용 상황과 함께 서비스 부하를 관찰할 수 있어 이후 배포 파라미터 조정의 근거가 됩니다.

### 로컬 모델, 퍼블릭 클라우드, 자체 구축 AI Gateway 계정의 통합 관리

실제 환경에서는 로컬에 배포한 모델, 퍼블릭 클라우드 모델, 자체 구축 AI Gateway가 동시에 존재하는 경우가 많습니다. 1Panel v2.5.0은 **모델 서비스** 모듈을 전면 재구성하여 로컬 모델 서비스, 퍼블릭 클라우드 모델 계정, 자체 구축 AI Gateway의 모델 계정을 중앙에서 관리합니다. 이를 통해 서로 다른 출처의 모델 서비스를 쉽게 확인하고 유지 관리할 수 있습니다.

서비스 출처별로 연결 주소와 접근 자격 증명을 설정하고, 계정의 모델 목록을 확인하며 연결을 검증할 수 있습니다. 배포와 연결이 완료되면 서비스 정보와 사용 가능한 모델이 더 명확해지고, 이후 사용과 벤치마크를 위한 통합 선택 진입점이 마련됩니다.

### 다양한 벤치마크 프리셋 제공

모델을 공개한 뒤에는 실제 부하에서의 성능을 파악해야 합니다. 첫 Token 반환 시간, 지속 출력 속도, 동시성 증가에 따른 처리량 등이 대표적입니다. 1Panel v2.5.0은 모델 서비스 벤치마크 기능을 제공하며, 대상 서비스와 모델을 선택한 뒤 빠른 검증, 표준 테스트, 전체 테스트 등의 프리셋으로 목적에 맞는 성능 테스트를 실행할 수 있습니다.

요청 길이, 출력 길이, 동시성을 조정할 수 있고 첫 Token까지의 시간(TTFT), 요청 지연, Token 처리량 등의 결과를 확인할 수 있습니다. 동일한 프리셋으로 서로 다른 배포 설정을 테스트하면 파라미터 변경에 따른 변화를 파악하기 쉬워 리소스 계획과 서비스 튜닝에 참고할 수 있습니다.

## 추가 신규 기능

- **가상 머신** — 가상 머신 관리 기능을 커뮤니티 에디션 사용자에게 개방.
- **개요** — GPU 상태 보기와 vLLM Token 처리량 모니터링을 추가하고 여러 디렉터리 바로가기를 지원.
- **에이전트** — DeepSeek Harness와 OctoP 지원.
- **MCP 관리** — 1Panel MCP 서비스 관리 기능 추가.
- **웹사이트** — 성능 조정에서 리버스 프록시 타임아웃을 설정할 수 있음.
- **인증서** — 발급된 인증서를 여러 로컬 디렉터리로 한 번에 배포할 수 있고, 자체 서명 루트 인증서를 가져올 수 있음.
- **컨테이너** — 컨테이너 디렉터리에 파일을 일괄 업로드할 수 있음.
- **컨테이너** — 이미지 업데이트 감지와 상태 표시를 추가하고 컨테이너 목록에서 일괄 업그레이드를 지원.
- **컨테이너** — Docker Hub의 원격 이미지 검색 지원.
- **컨테이너** — NVIDIA GPU 런타임 설정 스위치 추가.
- **예약 작업** — URL 접근 작업에서 User-Agent 요청 헤더를 설정할 수 있음.
- **리소스 동기화** — PHP 확장 템플릿을 노드 간에 동기화할 수 있음.
- **운영 리포트(X-Pack)** — 운영 리포트 기능을 프로페셔널 에디션 사용자에게 개방.
- **멀티 노드(X-Pack)** — 기존 설치 패키지로 노드를 설치하고 업그레이드할 수 있음.

## 개선 사항

- **앱 스토어** — 로컬 앱 동기화 시 하위 노드를 포함할 수 있고, 이미지 접두사를 개별 설정하고 활성화/비활성화할 수 있으며, 동기화 시 리소스 요청을 줄임.
- **에이전트** — MiniMax Flash 모델 목록과 기본 설정, DeepSeek 기본 모델 이름을 업데이트.
- **웹사이트** — Brotli 설정이 아직 적용되지 않았을 때의 상태 안내를 개선.
- **런타임** — 업데이트 시 이미지 가져오기가 완료된 후 기존 컨테이너를 중지하여 이미지 가져오기로 인한 서비스 중단 시간을 단축.
- **데이터베이스** — 데이터베이스 사용자 이름과 비밀번호 검증 규칙을 통일.
- **컨테이너** — 생성 시간 기준 정렬을 지원하고 정렬 해제 시 기본 순서로 복원하며, 목록이 오랫동안 로딩 상태로 남는 문제를 완화.
- **파일** — 이름 변경 시 Esc 키와 취소 처리 로직을 개선하고, 민감한 파일 작업의 출처 검증과 이력 기록의 출처 추적을 강화.
- **터미널** — 다크 모드에서 터미널 바로가기 테두리 표시를 개선.
- **인터페이스 설정** — 작업 로그와 삭제 확인 대화상자를 통일하고 Enterprise Edition 로그인 페이지 배경을 업데이트.
- **로그 감사** — 신뢰할 수 있는 프록시 환경에서 클라이언트 IP 기록과 로그인 정보 보존을 개선.
- **패널 설정** — 취소된 API Key를 삭제할 수 있고, 백업 스토리지와 HTTPS 프록시 인증서 검증을 개선하며 사용자 지정 CA 인증서를 지원.
- **시스템** — 표 툴팁 위치를 통일하고 페이지당 최대 항목 수를 늘리며 표의 반응형 레이아웃을 개선.
- **시스템** — 만료된 세션과 자격 증명 사용에 대한 접근 제한을 강화하고, 외부 리소스 요청의 TLS 인증서 검증을 개선하며 Markdown 및 HTML 파싱 의존성을 업그레이드.
- **멀티 노드(X-Pack)** — 노드 간 SFTP 업로드 속도를 개선하고 노드 데이터 동기화 재시도 시간을 연장.

## 버그 수정

- **앱 스토어** — "+" 또는 "-0"으로 시작하는 숫자 비밀번호가 앱 설치 또는 앱 파라미터 변경 시 변경되는 문제를 수정.
- **앱 스토어** — 앱 업그레이드 시 환경 변수 값이 변경되는 문제와 배포 중단된 버전의 앱을 업그레이드할 수 없는 문제를 수정.
- **앱 스토어** — 노드 프록시를 통해 접근할 때 앱 아이콘 리디렉션이 비정상인 문제와 리소스 캐시 새로 고침 및 PHP 런타임 버전 옵션의 문제를 수정.
- **에이전트** — Hermes WeChat 채널 설정 시 모듈 누락이 표시되고 QR 코드가 표시되지 않는 문제를 수정.
- **에이전트** — OpenClaw 업그레이드 후 Feishu 플러그인 호환성 문제를 수정하고 기존 Feishu 설정을 유지하도록 함.
- **웹사이트** — PHP 런타임 변경이 하위 사이트에 동기화되지 않는 문제를 수정.
- **런타임** — 프로젝트 터미널에서 컨테이너를 찾을 수 없고 연결할 수 없는 문제를 수정.
- **데이터베이스** — 관리 도구 진입점이 앱의 사용자 지정 웹 접근 주소를 사용하지 않는 문제를 수정.
- **컨테이너** — 컨테이너 편집 후 목록으로 돌아갈 때 검색 조건이 사라지는 문제와 앱 인스턴스 이름에 대문자가 포함된 경우 로그를 정리할 수 없는 문제를 수정.
- **파일** — 이름 변경 시 같은 이름의 대상 파일을 바로 덮어쓰는 문제, 다운로드 저장 경로가 선택한 디렉터리를 벗어날 수 있는 문제, tar 압축 명령 인수 주입 문제를 수정.
- **터미널** — 노드 추가 후 자동 키가 올바르게 표시되지 않아 연결 시 여전히 SSH 비밀번호를 입력해야 하는 문제를 수정.
- **예약 작업** — 스크립트 라이브러리 동기화 시 오래된 리소스 캐시를 사용하는 문제를 수정.
- **로그 감사** — 웹사이트 PHP 버전을 전환하거나 PHP 런타임을 삭제할 때 작업 로그에 리소스 이름 대신 리소스 ID가 표시되는 문제를 수정.
- **패널 설정** — 보안 진입점을 다시 활성화한 후 패널에 접근할 수 없는 문제와 백업 계정 이름 검색이 비정상인 문제를 수정.
- **시스템** — `1pctl` 명령으로 비밀번호를 변경할 때 비밀번호 복잡도 설정을 따르지 않는 문제를 수정.
- **시스템** — 서머타임 종료 후 중복 시간대에 시간을 동기화하면 시스템 시계가 1시간 뒤로 돌아가는 문제를 수정.
- **WAF(X-Pack)** — 웹사이트 설정을 열 때 오류가 발생하는 문제와 커뮤니티 에디션 하위 노드의 기본 API가 허용되지 않는 문제를 수정.
- **웹사이트 모니터링(X-Pack)** — 요청 로그 통계 오류를 수정.
